# 召回与交付v4预注册

复用v3冻结语料、片段ID、权重、dev（官方60/仓库50）和官方英文译文。仅dev加载，确认题不经通用校验器提前读取。指标为AI编写稀疏原始来源证据覆盖，不是回答正确率。

## 独立实验单元

| 组 | 变化 | 保持不变 |
|---|---|---|
| B5 | 原始global30控制 | 完整原问题重排、Top5、1200 token/4000字符、原邻接规则 |
| B8 | 交付Top8 | 候选、分数、排序、预算和邻接规则与B5相同 |
| D5 | 原问题加深召回的预算对照 | 保留B5候选，只补最多30个新候选，完整原问题重排 |
| Q5 | 原问题+带身份上下文的子问题召回 | 保留B5候选，只补最多30个新候选，完整原问题重排 |
| L5 | BM25使用标题/来源/前文增强视图 | dense原始，重排/交付只使用原文 |
| E5 | dense使用同一增强视图 | BM25原始，重排/交付只使用原文 |
| LE5 | 两路增强组合，探索性 | 重排/交付只使用原文 |

7组×110题=770条主检索。B5逐题复现v3的排名、正文与43/54、40/50交付。B8记录实际Top8，不把它的交付叫Top5完整。

Q5复用v3问题条件，不再生成条件。共享上下文为原问题逐字技术标识符；无拉丁标识符时使用原问题。各条件增加这个前缀，版本不作为每个产品的统一硬过滤。这个首轮身份保护是共享上下文，并未声称已实现产品级版本绑定。不得加入问题未提供的答案项。每个子问题BM25/dense各取30，跨查询RRF选最多30个新增ID。D5每路取30×(1+子问题数量)，也只补30个新ID，控制每路累计候选名额；实际模型调用和耗时并不相等，单列记录。

索引增强完全由语料计算：文件名、已有产品/版本、章节标题，以及同来源同父段且行号在前的最后一条不超过160字符的完整非空行；代码段不提供前文。没有合适前文时只加标题。前文采用完整行而非推断摘要，可能引入无关信息；本轮不事后改写。增强视图只参与检索，原文用于重排、邻接、引用与评测。索引在独立data目录，身份包含语料、recipe源码和模型快照哈希。视图片段保持原ID/定位并记录原正文与视图哈希，不改变原索引。

所有新增候选仅用原始完整问题+原始正文统一BGE重排；精确query/body/model缓存，原候选分数可从冻结基线导入，新增分数不能由子问题分数替代。记录候选、查询、排名、实际上下文、输入截断、新增评分对数；正文不能由生成模型改写。

## 统计和推进

4个官方交付主对照：B8-B5、Q5-D5、L5-B5、E5-B5，Holm校正。按原15/13簇配对bootstrap10000次seed42、簇符号置换；候选完整的配对统计及LE5、各组相对B5为探索性。分列候选不足、候选完整但未覆盖、TopK完整但打包失败、邻接补齐、实际截断，记录改善/退化ID。

门槛沿用官方≥44/54、仓库≥40/50，002-1与004-4交付完整，无新增已确认版本或引用支持错误。并列按官方交付、仓库交付、官方nDCG@5、较少新增检索调用、B8/D5/L5/E5/LE5/Q5顺序选择。dev门槛不等于统计确证；默认不自动切换。

无合格组时诊断使用Q5。固定v3的23个生成样本：同轮B5与候选各23条新生成，共46条；不再重复oracle。记录完整提示/usage、格式与引用ID，事实仍独立人工pending。B8会改变邻接预算占用，需核查005-2等原邻接补齐题，不能只看Top8排名。

在固定23题交错执行baseline/候选各一次禁用查询/候选/评分缓存的实验路径延迟对照；模型预热，官方冻结翻译共用。索引构建成本独立记录。若未通过dev门槛，停止确认评测；若通过，先冻结选定参数和生成观察，再仅评测官方holdout60/仓库test100的baseline与胜出组一次，译文在冻结后生成并共用。不根据确认成绩改参数。独立人工事实审核仍是默认切换的前置条件。

原v3产物不修改。新协议、源码归档、候选/评分缓存、上下文、统计、生成、索引记录、延迟与usage写入本目录独立run；结论追加日志。
