实模两种Agent会自行生成不同查询，组间差异不能全部归因于排序。
上表固定工具返回的排序对照没有新增模型请求或检索，只检验正文选择，不证明新答案更好。
仓库题的自选查询多为英文或技术短句；原题为中文。这轮无法单独确定语言、改写、候选预算或稀疏标签中哪项造成缺口。
缺gold仍可能有合法替代证据，需独立审核；不能把标签未交付直接判为答案错误。
