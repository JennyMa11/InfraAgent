# 本轮验证集决策

本轮完成等价证据v2、六组实际模型对照和配置选择。模型仍为BGE-small-zh-v1.5与
bge-reranker-base；没有执行新的test查询。

## 标注与比较依据

新增27条原文内容判断，涉及dev25题及此前发现漏标的test12题。每条判断保存引用、行号、
固定仓库版本、SHA256和理由。150题的ID、问法、分组与原始证据未改变。此为已识别等价
内容的补标，不是全库穷尽判断；AI审核尚需人工验证，候选池覆盖偏差仍然存在。

不同方法在同一50题v2标注上比较。“完整证据命中@5”要求前五块覆盖至少一组替代证据的
全部片段；不要求把所有等价来源都召回。子块Recall另行保留，补标后的分母不同，不与v1
混用。排名复现核验显示原始混合截断重排的50题Top10均与旧报告一致：其命中率由旧标签
下78%变为新标签下82%，这4个百分点来自标注变化。

## 结果与选择

完整六组指标见 `comparison.md`。原始分块的BM25＋重排为43/50题完整命中，即86%，
证据MRR@5为0.691，P50约565ms。按预先定义的“命中率、MRR、延迟”顺序选择该方案。

原始混合截断重排和完整并集重排均为82%；并集方案的MRR从0.695到0.700，但P50从
582ms增至840ms，本轮没有命中率收益。标题方案三组均为84%，最好MRR为0.705，P50
分别为736/809/1241ms，尚未表现出命中率与延迟的综合优势。

标题方案同时改动标题层级、模型输入和结构块清理，不能把结果归因于单独一个机制。
86%与84%只差一题；50题仅来自13个概念组，问法成对相关，没有显著性检验或泛化结论。

## 是否更换模型

**本轮暂不更换模型。** 当前已验证的推荐是BM25召回30个候选，再由现有reranker排序。
其他模型尚未比较，不能预先保证替换能提升。BGE继续用于现有语义分块和可选向量通道。
推荐方案尚有7道未完成标注证据覆盖的dev题，保存在 `selected-failures.json`，涉及MoE
结果归回、前缀共享因果性、GQA收益、KV公式、采样分布处理与端侧量化。后续应先核查这些
题的证据完整性与候选阶段，再安排独立、固定协议的模型对照。

## 使用推荐配置

`recommended-config.json` 保存可审阅配置；原始模型索引无需重建。

```bash
uv run --all-extras infra-rag --backend bge \
  --data-dir data/repository-index/bge-e4579f5f84b9 --rerank \
  search 'DDP梯度Bucket如何实现计算通信重叠？' --strategy bm25 --domain infra --top-k 5
```

保留标题层级的索引为 `data/repository-index/bge-e4579f5f84b9-headings-v1`，需配
`--heading-context` 使用。完整并集由 `--fusion-candidates union` 控制，作为可复现实验
选项保留；全局默认仍兼容原索引。
