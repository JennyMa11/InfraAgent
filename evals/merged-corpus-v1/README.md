# 合并语料索引 v1

将40篇冻结官方材料与87篇三仓库正文建立为独立索引。原文文件、稳定chunk ID、行号与来源路径不改动；题目、参考答案、译文不入库。索引目录由输入清单、输入索引hash和去重结果确定。

`corpus-manifest.json` 保存全部127来源的原始来源URL、commit/release、文件hash、集合类别，以及被删除片段到保留片段的映射。索引旁的 `provenance.json` 保存同样记录，专用启动器在返回证据中附加 `provenance`。原文依然保存在两批冻结语料的原目录；运行时需要这些文件。

去重仅删除跨来源、去除首尾空白后完全相同且至少100字符的片段；优先保留官方来源。语义相似或版本不同的正文保留。近重复审计采用40字符片段、20字符步长的文档包含率，阈值0.5，属于粗略筛查，不能证明没有语义重复。完全重复片段也可能具有不同的上下文，完整来源与删除映射仍可供核对。

```bash
uv run --all-extras python scripts/merge_corpus.py
uv run --all-extras python scripts/merge_corpus.py --serve --port 8001
```

专用启动器默认沿用英文翻译检索、BGE、BM25、候选并集30/路、重排、1200token/4000字符上下文。模型配置读取 `.env.llm`，不改默认配置或现有服务。可用 `--query-language bilingual` 或 `--query-language none` 显式切换查询语言。

固定中文dev60的三组对照见 `dev-20261002/report.md`。英文译文复用旧版冻结结果，避免翻译变化影响比较；合并英文组隔离语料扩充的影响，合并双语组观察查询语言的额外影响。回答样本在检索前固定：每题型按ID选前2题，12题×3组。同一模型和生成预算650token，原始回答、实际证据与调用记录全部保留。

新增中文材料可能提供未标注的等价证据；已有官方稀疏gold不能衡量所有新增材料的相关性。旧拒答题的不可回答状态也仅针对官方语料，需要重新判断。dev实验不代表holdout或总体问答准确率；事实指标等待独立人工复核，AI审阅单独标记。

综合结果与AI逐题复核见 [comparison.md](comparison.md)，包含官方dev60、原生中文覆盖6题、48条回答与具体失败案例。
