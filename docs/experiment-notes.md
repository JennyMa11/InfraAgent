# 本次实验的失败案例与解释

本次使用AI 自编笔记与 60 道题，结果仅作局部基线。未以题集调参，也没有显著性检验。

- 混合检索 q30：“每个设备手里只有一段参数，要让每张卡拿到所有原始片段，用什么操作？”
  AllGather 的相关子块未进入 Top-5。这是一道模糊表达题，术语和参数分片主题的混淆值得
  在独立验证集上进一步分析，不能用高平均 Recall 掩盖失败。
- 加入重排后 q14：“一个超长输入阻塞其他用户继续出字，调度上能怎样缓解？”
  Chunked Prefill 的相关子块未进入 Top-5。通用 reranker 在本次题集没有稳定改善排序，
  因此保持为可选项；不默认把启用重排宣传为精度提升。
- 六图多模态验收中，图注重排 Recall@5 从 1.000 降到 0.917。整图与不同区域的说明
  相似，重排结果可能挤占其他相关整图的位置。下一步可在独立标注图集中评估父图去重、
  区域内容说明及视觉排序融合，不能只靠重复图注判断区域相关性。

窗口和语义分块的相关子块粒度不同：一个较大的窗口可能同时覆盖两个证据，语义分块
则需要召回两个较精细的块。应结合上下文噪声、证据覆盖和实际问答效果审查，不直接把
两者 Recall 的大小等同于切分质量。
