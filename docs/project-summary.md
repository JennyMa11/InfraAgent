# Infra 知识 RAG 检索系统

作为多 Agent 的独立专业知识支撑模块，通过 HTTP 返回可定位的证据。
InfraResearch-Agent 可继续负责研究计划、工具调用与报告生成。

## 已实现

文本采用“粗分块—标题与语义聚合—句群细化”，加入 jieba 辅助标题判定和 BGE
句向量边界判断。PDF 使用 PyMuPDF 区分文本和内嵌图片、定位页码与邻近图注。
图片采用 OpenCV 边缘/轮廓粗处理、PIL 裁剪、CLIP 与几何关系聚合，以及大区域细化。
父子元数据和父索引关联同一语义块或整图，检索后回填关联上下文。

Chroma 中维护 BGE 文字/图注集合和统一 CLIP 图文集合，通过 BM25、BGE、CLIP 多路召回
及 RRF 融合候选，可选 bge-reranker-base 对文字和图注排序。支持领域与模态过滤、
同路径来源替换、活动来源删除、CLI、FastAPI 及独立父块查询。

JSON 测试集以AI 编写的证据短语在检索前解析子块标签，输出 Recall@K、Precision@K、F1@K、
MRR、nDCG、逐题结果与延迟。已运行真实 BGE/reranker/CLIP 预检、60 题文本消融和
六张合成图片的真实图文验收。

## 简历描述草稿

**Infra 专业知识 RAG 检索系统开发**（按实际投入填写时间）

技术栈：Python、FastAPI、BGE、ChromaDB、BM25、bge-reranker-base、CLIP、jieba、
PyMuPDF、PIL、OpenCV。

面向推理服务、分布式训练、GPU、系统软件和云原生知识，开发多 Agent 可调用的独立
RAG 检索支撑模块。设计文本三级语义分块与图片区域分块，保留父子关系、来源定位及
模态元数据，利用父索引回填完整上下文。构建 BGE 文本与 CLIP 图文向量集合，通过
BM25、向量检索和 RRF 融合实现多模态混合召回，支持可选文本 Cross-Encoder 重排。
建立 60 道 Infra 问题的子块证据标注和策略消融，在本地真实 BGE 实验中，混合检索
Recall@5 为 0.983、MRR@5 为 0.931，并保留重排退化结果及逐题失败案例。

这些指标来自AI 自编的小型学习笔记题集，不能描述为生产知识库准确率或泛化效果。
CLIP 文本分支处理原始文字，BGE 空间独立；重排图片使用图注，不能写成直接视觉重排。
不宣称子图检测“精准”、知识碎片化问题“彻底解决”或实验差异具有统计显著性。

## 后续实验

扩充真实官方文档和论文、复杂架构图、跨页与跨来源问题，进行人工子块标注；以独立

已新增来源/图注哈希清单、持久向量缓存、未变化来源跳过与历史生成物清理。
缓存覆盖 BGE 分块/索引编码与最终 CLIP 图文编码；完整版本集合写入仍保留。

原排名策略和索引指纹保持兼容，可使用 legacy 上下文模式对照历史行为。

固定中文真实仓库 dev50 的新旧上下文模式 BM25 排名/分数一致。
这是工程正确性与交付改进，不是检索准确率提升结论；细节见
